
# ORA Authentication Service

Authentication and User Management microservice
for the Oromo Research Association Digital Platform.

## Technology

- Node.js
- Express.js
- TypeScript
- PostgreSQL
- Prisma ORM
- JWT
- Argon2id password hashing

## Responsibilities

- User registration and login
- Authentication and authorization
- User profile management
- Role-based access control
- Permission management
- Email verification
- Password recovery
- Session and refresh token management
- Security audit logging

## Database

Development database: ora_platform

Database schema: auth

## API Prefix

/api/v1/auth
/api/v1/users
/api/v1/roles
/api/v1/permissions
